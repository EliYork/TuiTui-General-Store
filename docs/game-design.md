# 游戏设计说明

## 游戏核心循环概述

目标玩法是典型推币机循环：

1. 玩家点击投币
2. 新硬币进入推币台
3. 场内硬币与推板、场景、奖励物产生互动
4. 触发掉落或奖励反馈
5. 玩家获得资源
6. 用资源继续投币或升级

第一阶段只保留这个循环里最靠前的一段，重点是把工程骨架搭稳，而不是提前把所有系统做满。

## 第一阶段范围

第一阶段只实现：

- 游戏主循环
- 基础场景绘制
- 推板周期性往复运动
- 投币按钮
- 硬币生成
- 硬币的基础位置与速度更新
- HUD 基础信息展示

第一阶段明确不实现：

- 真正的推板碰撞
- 掉落判定
- 奖励块生成与结算
- 升级与数值成长
- 音效资源
- 美术资源
- 商业化系统

## 后续阶段建议

### 第二阶段建议

优先接入“推板与硬币碰撞”和“前沿掉落判定”。

原因：

- 这是最接近真实推币机手感的核心
- 做完后才能验证场景坐标、对象结构、更新顺序是否合理
- 这一步完成后，奖励块、结算、升级才有明确依附点

### 第三阶段建议

在第二阶段稳定后，再加入：

- 奖励块与奖励掉落
- 简单结算
- 本地存档
- 基础音效
- 可调整数值配置

### 更后续阶段

等玩法核心稳定后，再考虑：

- 美术升级
- 动效优化
- 云同步
- 活动与长期留存系统
