# 微信小游戏 2D 推币机 - 第一阶段骨架

## 项目简介

这是一个面向微信小游戏环境的 2D 推币机项目第一阶段骨架。

本阶段目标不是把完整商业化内容一次性做完，而是先建立一个“最小功能可运行 + 结构正式可扩展”的基础工程。当前版本只实现最核心的玩法闭环：主循环、基础场景、推板往复运动、点击投币、硬币对象更新与渲染，以及少量 HUD 展示。

源码使用 TypeScript 组织，运行产物面向微信小游戏 JavaScript 环境。

## 当前已实现内容

- 微信小游戏最小入口文件：`game.js`、`game.json`
- TypeScript 源码目录与 `tsc` 编译配置
- 游戏主循环
- 基础推币台场景绘制
- 一个会周期往复运动的推板
- 一个右下角“投币”按钮
- 点击后生成硬币对象
- 硬币基础更新逻辑
- 基础 HUD：金币、场上硬币数量、已投数量、状态提示
- 预留接口：
  - `saveGame()`
  - `loadGame()`
  - `playSound(name)`
  - `syncToCloud()`
  - `spawnReward()`

## 如何运行

### 1. 安装 TypeScript

如果本机还没有安装依赖，在项目根目录执行：

```bash
npm install
```

### 2. 编译 TypeScript

```bash
npm run build
```

编译后会生成 `dist` 目录中的 JavaScript 文件。

### 3. 用微信开发者工具打开

1. 打开微信开发者工具
2. 选择“小游戏”
3. 导入当前项目根目录
4. 编译并运行

如果你直接使用当前仓库内已提供的 `dist` 文件，也可以先导入查看，再按后续迭代继续用 `tsc` 重新生成。
